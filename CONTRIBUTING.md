# Contributing

Use Python 3.10 and install `requirements.txt`. Run `python scripts/check_install.py` before submitting changes.

For a bug report, include the notebook name, cell, traceback, operating system and package versions. Do not include private data or credentials.

Keep changes to preprocessing, DDI definitions, model settings and evaluation protocols explicit. Changes to those settings may invalidate existing caches and alter the scientific results. Submit numerical changes separately from formatting changes.

Do not commit generated `result/` files, downloaded observations, model weights or notebook execution outputs. Preserve all third-party notices and licenses.
